# Reglas de Proyecto - App Reemplazos

## 🔒 Protocolo de Memoria y Continuidad Obligatorio
Para mantener el contexto a largo plazo en este proyecto, DEBES seguir ESTRICTAMENTE este flujo de trabajo:

1. **Lectura Inicial Obligatoria:** Lo primero que debes hacer al iniciar una sesión en este workspace es **leer el archivo `AGENT.md`** que se encuentra en la raíz del proyecto para obtener el contexto general y la arquitectura del sistema.
2. **Revisión de Memoria:** A continuación, debes revisar la carpeta `memoria/` y leer el último archivo de bitácora para entender en qué quedó el trabajo anterior.
3. **Cierre de Sesión:** Es obligatorio crear un nuevo archivo Markdown en `memoria/` al finalizar tareas importantes, con el formato `YYYY-MM-DD_HH-MM_Tema_Breve.md`. Registra en él los bugs corregidos, comandos ejecutados y cualquier cambio arquitectónico.
